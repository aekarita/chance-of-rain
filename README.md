# chance-of-rain
# 🌦️ Rainie Pastel Forecast ✨
**"A Minimalist & Cute Real-time Rain Probability Tracker"**

Rainie Pastel is a lightweight, web-based tool designed to provide highly accurate rain forecasts base on your location using the Tomorrow.io API. Built with a "Pastel Pink" aesthetic, it offers a user-friendly experience for those who want to stay dry in style.

### 🌸 Features
* **Hyperlocal Precision:** Delivers rain probability updates every 5 minutes (for the first 30 mins) and hourly for the next 6 hours.
* **Privacy First:** No server-side storage. Your API Key is stored locally in your browser's `localStorage`.
* **Bilingual Support:** Easily toggle between **Thai** and **English**.
* **Zero-Overhead:** No backend required. Runs purely on GitHub Pages.
* **Responsive & Cute:** Hand-crafted UI using the 'Mali' handwriting font for a soft, friendly look.

### 🚀 Getting Started

To use this app, you will need your own API Key from Tomorrow.io (it's free!).

1.  **Get your API Key:** Sign up at [Tomorrow.io](https://app.tomorrow.io/signin).
2.  **Find your Key:** Navigate to the [API Keys Dashboard](https://app.tomorrow.io/development/keys).
3. Run the App: Open the live link: [https://aekarita.github.io/chance-of-rain/](https://aekarita.github.io/chance-of-rain/)
4.  **Setup:** Paste your key into the "API Key" field (the app will remember it for your next visit!).
5.  **Forecast:** Enter your Latitude and Longitude and hit the button! 💖

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **API:** [Tomorrow.io Weather API](https://www.tomorrow.io/)
* **Typography:** Google Fonts (Mali)

### 🌸 Features (ทำอะไรได้บ้าง?)
* **Hyperlocal Accuracy:** ดึงข้อมูลพยากรณ์ละเอียดระดับ 5 นาที ยาวไปถึง 6 ชั่วโมงข้างหน้า
* **User-Centric Privacy:** ไม่เก็บ API Key ไว้ที่เซิร์ฟเวอร์ แต่บันทึกไว้ใน `localStorage` ของผู้ใช้เอง ปลอดภัย 100%
* **Bilingual Support:** รองรับทั้งภาษาไทยและภาษาอังกฤษ
* **Cute UI:** ดีไซน์ธีมสีชมพูพาสเทล ฟรุ่งฟริ้ง สบายตา (ใช้ฟอนต์ Mali สุดน่ารัก)

### 🚀 Getting Started (เริ่มใช้งาน)
คุณสามารถเข้าใช้งานผ่านหน้าเว็บได้ทันทีที่: [https://aekarita.github.io/chance-of-rain/](https://aekarita.github.io/chance-of-rain/)

**วิธีใช้งาน:**
1. **สมัครรับ API Key:** ลงทะเบียนใช้งานได้ที่ [Tomorrow.io](https://app.tomorrow.io/signin)
2. **คัดลอก API Key:** ไปที่หน้า [API Keys Dashboard](https://app.tomorrow.io/development/keys) เพื่อก๊อปปี้ Key มาใช้งาน
3. **เปิดใช้งานแอป:** คลิกที่ลิงก์นี้เพื่อเข้าสู่เว็บไซต์: https://aekarita.github.io/chance-of-rain/
4. **ตั้งค่าเริ่มต้น:** วาง Key ที่ก๊อปปี้มาลงในช่อง "API Key" (ระบบจะจำไว้ให้โดยอัตโนมัติ เปิดใช้งานครั้งต่อไปไม่ต้องพิมพ์ซ้ำแล้วจ้า!)
5. **ดูพยากรณ์ฝน:** ใส่พิกัด Latitude และ Longitude ของคุณ แล้วกดปุ่มลุยได้เลย! 💖
