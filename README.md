# 🌦️ Rainie Pastel Forecast ✨
**"A Minimalist & Cute Real-time Rain Probability Tracker"**

Rainie Pastel is a lightweight, web-based tool designed to provide highly accurate rain forecasts using the Tomorrow.io API. Built with a "Pastel Pink" aesthetic, it offers a user-friendly experience for those who want to stay dry in style.

---

### 🌸 Features
* **Hyperlocal Precision:** Delivers rain probability updates every 5 minutes (for the first 30 mins) and hourly for the next 6 hours.
* **Privacy First:** No server-side storage. Your API Key is stored locally in your browser's `localStorage`.
* **Bilingual Support:** Easily toggle between **Thai** and **English**.
* **Zero-Overhead:** No backend required. Runs purely on GitHub Pages.
* **Responsive & Cute:** Hand-crafted UI using the 'Mali' handwriting font for a soft, friendly look.

### 🚀 Getting Started

To use this app, you will need your own API Key from Tomorrow.io (it's free!).

1.  **Get your API Key:** Sign up at [Tomorrow.io](https://app.tomorrow.io/signin).
2.  **Find your Key:** Navigate to the [API Keys Dashboard](https://app.tomorrow.io/development/keys).
3.  **Run the App:** Open the live link: `[https://aekarita.github.io/chance-of-rain/]`
4.  **Setup:** Paste your key into the "API Key" field (the app will remember it for your next visit!).
5.  **Forecast:** Enter your Latitude and Longitude and hit the button! 💖

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **API:** [Tomorrow.io Weather API](https://www.tomorrow.io/)
* **Typography:** Google Fonts (Mali)
